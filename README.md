# Meridian Homebrew Tap

Homebrew formulae and casks for [Meridian](https://meridian.online) tools.

## Installation

```bash
brew tap meridian-online/tap
brew install finetype
brew install brightfield
```

Or install directly:

```bash
brew install meridian-online/tap/finetype
brew install meridian-online/tap/brightfield
```

## Available packages

| Package | Kind | Description |
|---|---|---|
| [finetype](https://github.com/meridian-online/finetype) | formula | Semantic type classifier for data profiling — detects 151 data types from raw strings |
| [brightfield](https://github.com/meridian-online/brightfield) | cask | Grammar-of-graphics renderer for Meridian data (macOS only) |

## Brightfield is a cask

`brew install meridian-online/tap/brightfield` (or `brew install --cask meridian-online/tap/brightfield`) installs Brightfield.app into your Applications folder (`/Applications` by default) and a `brightfield` command. It is macOS only, and the app is notarised, so Gatekeeper accepts it.

### Moving from the formula

Brightfield used to be a formula. If you installed that, `brew update` moves the install to the cask for you once you have trusted it:

```bash
brew trust --cask meridian-online/tap/brightfield
brew update
```

Without that trust, `brew update` prints the commands instead. You can also do it by hand:

```bash
brew uninstall --formula brightfield
brew install --cask meridian-online/tap/brightfield
```

The cask refuses to install while the formula is still linked, and names that uninstall command.

## Updating

Each package is regenerated by its own project's release workflow when a version tag is pushed, so the tap follows a new GitHub release without a hand edit. The brightfield cask is generated by brightfield's release workflow and pushed here with each notarised release.

A formula or cask in this repo is generated output. Edit it in the project that emits it (for brightfield, `scripts/write-brightfield-cask.sh`); the next release of that project overwrites the copy kept here.

To get the latest of either:

```bash
brew update
brew upgrade finetype
brew upgrade --cask brightfield
```
